# 请重点质疑什么

这份文件随证据更新，最终数值以同目录最终报告和 run/derived 为准。它不把预计结果写成结论。

1. **粗分组有没有掩盖组内相反偏好？** 原 P1 的两个 28-SM 组不能代表两个物理内存节点。逐 SM 的小工作集残差确有稳定例外，因此增加了单独冻结的公开 2-SM 分组和重新合并实验。请同时看原始图、缺格和大组结果，不能只挑一种图。
2. **测到的是访存，还是地址计算？** 原通用地址函数包含整数除法的倒数指令序列。原 P1 的吞吐路径不能据此冒称纯带宽瓶颈。补充版本将同一幂二窗口地址计算换成等价移位，并保存独立 cubin/SASS/原始数据；不能混合版本后算一个置信区间。新 consumer 的 slot 在线程序言中计算，部分 SASS 使用 uniform 指令，但不是整 CTA 只有一次硬件 POPC；额外算术/分支已计时。
3. **小集合的规律是不是缓存状态规律？** `.cg` 不是“绕过所有 cache”；scratch 扫描也不是硬件保证清空缓存。2 MiB 与 32 MiB、one-pass 与 repeat、primer/顺序变化要分别看。没有 L2/DRAM/remote transaction 计数，不能宣称远端流量下降百分比；也没有直接测 SM-to-SM 通信延迟。
4. **标定条件能否预测实际执行？** 低并发标定与真实多 CTA 消费不同。补充实验实际测最强等量小组及全卡等量合并组，并交换计算归属与存储布局。仍须检查独立分配、同一逻辑内容的四格交互和完整 makespan；仅训练热图不够。
5. **Graph 是否真的保持资源组？** 本机已用实际输出和 SM 记录验证公开 Green Graph。所有新增 kernel 分支计入计时。不要把两个 event 的最大值当总时间，也不要把含提交间隙的事件跨度叫 GPU busy time。
6. **M 是否超过更简单的静态 T？** 编译 micro 增加了无需数据重排的 T：用相同标定信息分配原位置任务。M 改变逻辑数据布局，但两者在这个均匀归约上的物理访问集合相同。分别测 M/T 与初始化差值；即使 M/N 好看，也不能据此宣称超过同信息静态方法或具有算法新颖性。
7. **这些是完整应用吗？** 三维高斯部分测了动态完整帧和原生 snapshot；稀疏部分是实际 CSR 结构、一般权值的 SpMV/SpMM；推理部分是合成 grouped GEMM 与 decode attention，没有真实 LLM 模型端到端 token 结果。micro 不能替代三族应用。
8. **数据散布是否就等于 home 混合？** 渲染统计是候选列表颜色起始地址的虚拟页数，未展开跨页属性或跟踪 early-stop，并非实际消费页数，但虚拟页不是 home。未在该应用 live allocation 上标定时，known-home fraction 仍为 0，不能套用已释放探针的标签。
9. **Native 是否足够强？** 使用成熟的 cuBLAS、cuSPARSE、CUTLASS attention 和原生 Graphdeco 数学体。库内部启发式选择并非遍历所有算法的最优性证明；旧 Q1 只是普通顺序控制。Graph 节点少也不自动更快。
10. **统计独立单位是什么？** CTA、帧与同一输入环请求不是独立样本。以分配/进程块为单位复算探索性区间；所有正负条件保留。三轮开发与正式结果分开。八策略正式测量前已从循环顺序修正为参考 Williams 顺序，同时平衡位置和56个有向相邻策略对；开发版保留，GPU cubin未改变。缓存状态/大小的固定次序以及更长历史效应仍不是完全随机化。事后细分资源实验也不能冒充原来预冻结的确认。
11. **开发／测试数据真的分开了吗？** 渲染实际程序在 P2/P4 都取 `camera_index % 4 == 2 + sequence`；Bonsai sequence 0 因此重叠。准备文件的 dev 标签没有进入执行程序。所有相机都是原训练场景相机，不是新视角质量留出。推理和 CSR 也明确是已见形状回归。
12. **功耗控制有没有被夸大？** 100 W 是功耗上限，不是每次相同瓦数，更不是锁频。实际频率、温度和锚点漂移均保留。不按快慢删块，不用频率回归把坏结果“修好”。第二功耗条件未完成时必须列 NA。
13. **一次性成本和生命周期呢？** 研究表征、初始化、标定、布局上传、Graph 捕获和每请求消费是不同成本。原生研究 setup 包含参考输出和诊断，不能叫纯部署启动。重新分配、扩容必须作废旧规则；如果没有部署方法，不填写虚构的回本次数。
14. **检查 PASS 究竟证明什么？** 整数 micro 检查全部逻辑归约，算子对 FP64 参考，渲染检查完整 color/T/contribution 的原生重放一致性并核对原数学体。渲染重放一致性不是独立图像质量提升。失败的 CUPTI 诊断记录也保留；修复后资格与正式记录分开。
15. **能否支持论文主张？** 最多按实测条件讨论可控经验亲和、适用范围、执行开销与反例。没有物理域接口和流量证据，不升级为已识别物理 NUMA；没有应用净收益，不升级为端到端优化；没有超过同信息 T 的增量，不制造方法贡献。任务包提供的相关论文摘要不是本次离线重审全文的新颖性证明。
