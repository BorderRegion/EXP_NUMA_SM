# 固定矩阵、统计与判定

## 1. 数量单位

| 阶段 | 计算 | 上限 |
|---|---|---:|
| S1局部复验 | 6进程×2集合×28组×4轮 | 1344个measured probe launch；不含warm/roster |
| S2桥接 | 6进程×2集合×2scope×3形态×6动作 | 432 phase |
| S3反事实 | 6进程×7 GPU profile×6动作 | 252 phase |
| S4部署/观测 | 6进程×2集合×2复用×4策略×2诊断 | 192主phase |
| S4原生锚 | 6进程×2集合×2复用×首尾 | 48 anchor phase |
| 合计正式phase | 432+252+192+48 | **924** |

一phase有独立预热和128次计时，不等于128独立实验。S1是诊断，不并入S2/S3 clean效应。S3只用2MiB；32MiB从S2/S4检验转移，不另开32MiB规则搜索。

程序化计划见 `tools/make_plan.py`。该工具不会控制GPU、改变机器状态或认为计划已经执行。

## 2. 数据块与次序

6个新进程块，彼此seed不同；每块拥有一个32MiB+guard的分配，2MiB为其前缀，32MiB为整个集合。保留同块基址与scope对象，减少一次比较中资源变化。不同进程可能复用物理页，不称物理独立。

一次恢复匹配组后，同块绝不依据计时重分组。S1分析只计算冻结方向，不能把S1当新的拟合数据。

六动作使用完整六行Williams次序 `[0,1,5,2,4,3] + block mod 6`。CASE顺序独立固定随机化。S4八个DIAG×policy用八行Williams的预定六行；明确不是完整八行平衡，不新增两个块去追漂亮平衡。主N也有独立计时，不以有利首尾锚替换。

同条件若合并动作的warmup、输入重用或graph准备改变，要在冻结前一次说明；正式阶段不按性能改顺序。因真实错误重编译，生成新epoch/source hash；旧失败留存，不把两版混成同一binary。

## 3. 统计

每个process/block先汇总动作均值和有符号log对比，再对6块bootstrap，20,000次，seed=2026101641。仅6块，区间均明确探索性。若单个块缺一个CELL，该块不能参与该四格交互；原记录保留，不能补0。

主要看四件事：
1. FULL/2MiB/H1/COMMON_PRIME 的 I_cell。
2. 相同条件 I_joint。
3. S4 FULL/2MiB/HOT one-pass 的 T_DIAG0/N_DIAG0。
4. S4 同条件 P_DIAG0/M_DIAG0。

全部给95%探索性区间；四项另外给Bonferroni98.75%边际区间，不宣称其他数百格也获得家族错误控制。不用p值或3%门槛省略实验。

所有比较都显示6个块，不只均值。不按温度或速度删块、不用时钟回归将速度校正成理想值。状态失效另列：cap变更/热保护/外部显著负载导致配对不再同条件时，先留原块为STATE_CHANGED，不用于稳定状态主汇总；不根据漂移正负追加替代计时；全部结果及稳定状态子集并列报告，缺格保留。软件错误修复后的资格和新计时版本单独记录，不回填旧块。

S1残差：原时序、固定方向的region contrast、缺格和row/column效应分别保留。相关性描述pattern重现，不能写成home分类准确率。I>0也不自动等于物理远端流量减少。

## 4. 该如何回答用户的NUMA担忧

| 数据形态 | 可支持的结论 | 不能下的结论 |
|---|---|---|
| frozen规则在新块重现，I_cell/I_joint跨order/owner方向一致 | 稳定可控的经验亲和 | 已破解物理home |
| 局部低并发正，H1 joint消失或反转 | 标定向实际并发迁移失败 | 所有NUMA不存在 |
| owner改变导致偏好跟着owner走 | cache/先前访问相关的证据 | 一定是哪一级cache，除非有独立证据 |
| payload改变会系统性改变方向 | 内容/数据路径因素尚未排除 | 纯地址物理hash已确立 |
| relabel改变物理集合/符号不补偿 | 协议/实现错误，修正后独立验证 | 新硬件发现 |
| 128B base shift后规则失效 | 冻结规则的坐标/分配适用域有限 | 物理地址完全均匀 |
| DIAG1好、DIAG0无效 | 观察相关，需要限制部署推论 | 数值正确就足以证明机制 |
| DIAG0的匹配优于反向，但不优于N | 亲和可利用但当前控制成本不回本 | 方法完全没有局部作用 |
| 对N有可靠净收益而M≈T | 静态亲和工程机会 | 联合布局有新的算法增量 |

“物理NUMA”至少还需要独立的服务域/地址归属或足够具体的硬件干预依据；普通L2 hit/DRAM byte计数与一次热图不够。缺物理指标不否定经验优化，但措辞必须降级。缓存尺度非均匀性仍然可能有价值，不因小于L2就删除。

## 5. 最终状态不是单个GO/STOP

生成下列五字段，每字段含实测方向、scope和unknown：
- `frozen_rule_repeatability`
- `cache_and_order_dependence`
- `low_to_high_concurrency_transfer`
- `diagnostic_free_deployment_effect`
- `numa_evidence_level`

允许多个事实同时成立，如：pattern高度重复＋高并发方向反转＋小量观测开销＋physical home未知。不要合并成“全部失败”。

本轮结束后不自动新增另一mask、125W大矩阵、第三种执行器、渲染/CSR/LLM候选。若存在明确机会，用当前证据说明下一步需要什么；没有则给出当前机制边界，不移动目标。
