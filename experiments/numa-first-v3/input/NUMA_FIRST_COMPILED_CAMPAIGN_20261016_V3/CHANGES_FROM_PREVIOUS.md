# 本版实质变化

- 原任务的主线重新统一为NUMA辨识→真实放置→无查询表编译特化；普通q1/cache方法不再能代替它。
- T10功耗/频率控制已获用户授权，改为协调保护服务、读回和恢复，而不是一律禁止硬件状态调整。
- 新kernel禁止per-task/per-page scheduling LUT。原数学索引保留；初始化分析表不得混进稳态查询。
- 先测实际C×D关系和相同地址跨任务位置，不从裁剪比例或Green组编号推断NUMA。
- 实际数据本地化与计算放置分开验证；不只把“任务进入了组”当成“访问已本地”。
- 所有三族应用先做原生瓶颈卡；没有真实地图时输出范围结论，不写候选NUMA效果。
- 保留简单静态NUMA和同融合强基线；增加布局/计算/联合与反向匹配消融。
- 首选初始化布局/短算术规则，或已有kernel内低成本router；不新加小调度kernel或CPU往返。
- 不用3%预测门槛替代小型实际交叉执行，不把每个阶段变成人工审批。
- 本包只含设计与CPU数学参考，没有真实NUMA地址hash、硬件控制执行结果或GPU性能数据。
