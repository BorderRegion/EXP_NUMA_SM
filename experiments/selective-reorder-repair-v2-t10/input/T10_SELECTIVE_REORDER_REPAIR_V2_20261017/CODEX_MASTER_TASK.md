# Codex 主任务书：T10 选择性静态重排 V2

**本包明确授权本轮新的S1–S5 GPU补充实验；上一份CPU收尾指令中的“不跑新GPU”仅约束旧轮，不再阻止本任务。旧数据仍只读。**

## 1. 目标不能偏移
用户要的是：按实际资源能力和生产—消费关系判断“该重排才重排”，未受益的计算直接保留成熟原生；决策尽量发生在初始化/编译期；算子内部不新增逐任务查询表或独立小调度kernel。

本轮修正测量与选择，不声称已识别物理NUMA。不能用SM屏蔽比例替代位置—数据/通信证据；也不能把纯LIB/SINGLE/SPLIT选择收益计成NUMA收益。

已有成熟P/R、DIAG0、直接slab地址、三种资源二分和两种消费者方向保持。**同一个9动作池**：LIB、SINGLE、SPLIT、PC0_0/1、PC1_0/1、PC2_0/1。新算法只有一个RESOURCE_V2，SHAPE_V2是同结构强基线，BASE是公共非位置选择。

不要增加kernel配方、S搜索、第三执行器或新硬件。为隔离本轮变化，复用上一轮 `bins.json` 的数学配方/S；它是已有动作池定义，不是本轮测得的生产最优。旧配方选择的局限要保留，不再用旧毫秒值训练。

## 2. 已知缺陷与本次解决方式
- 119/144首尾锚漂移>5%：先做同Graph A/A；正式比较改成相邻ABBA/BAAB，重型数值检查、建图与日志离开配对区间。
- SINGLE来自更早扫描：所有8个非LIB动作重新与当前LIB局部配对，不拼接旧校准时间。
- 全局绝对误差约590–1193us：改为直接预测 `log(T_action/T_LIB)`，用同尺度的单侧log残差；不是降低旧微秒门槛。
- `stable_sort`短排序堆分配：先应用保行为补丁；BASE/SHAPE不执行无用资源插值；新选择器导出无分配C++。
- PERMUTED差异未进入真实trace：三条主序列覆盖全部16个新shape；冻结预测后另生成有限disagreement见证序列，不看GPU赢家。
- 全部LIB时报告混淆：必须区分“动作池确实没有稳定额外空间”“预测不准”“保护/初始化不回本”“测量无法辨识”。不强迫开启至少一次PC。

## 4. 实现权限与运行状态
继续已有100W主条件。已批准的T10功耗/时钟协调可以执行，前提是实际有管理权限且在设备支持范围；保留风扇、过温、低转速降额和恢复。**不是重复向用户申请已经批准的研究设置。**无非交互管理入口则只记录一次缺项，使用动态频率条件继续；不猜密码、不绕权限、不关闭保护。不增加125W数据族，不重置GPU、不改驱动/TDR/固件。

一次性保存/恢复自己改变的字段。锁频不是关闭硬件降频；实际clock/readback与保护事件须记录。主测量状态在S1结束冻结；之后不为候选变更设置。

## 5. 正常流程不是人工Gate
S1只修一次有证据的测量路径，不无限等“稳定”。即使分辨率仍不够，也完成预定校准与有限真实部署；按噪声尺度限制小效应主张，不把全部退回LIB称为NUMA不存在。只有错结果、设备健康、权限/付费越界或改变数学合同才需要隔离/决定。

模型不能增加层层资格开关。运行决策仅：范围外→LIB；范围内→共享BASE；位置候选有预计净收益→采用；否则保留BASE。未知初始化成本不能填0。这里是方法的成本判断，不是人工批准点。
