# 本轮的设计约束（自包含，不依赖任何旧设计）

本文件列出本轮实验必须遵守的约束。每条都可以单独理解，读者不需要其他文件。

1. **内存 NUMA 不是本轮主线。** 本轮测量计算侧的有效容量、cluster 与资源分区。内存只作为对照变量，不要求先测物理地址映射。
2. **裁剪比例不等于可恢复的性能。** 例如 5070 Ti 相对完整 GB203 少 14 个 SM，即 16.67%。这是规格差异，不是调度可以找回的空闲算力。
3. **T10 不是理想的负对照。** 它可能有裁剪、虚拟化或未公开的资源差异。没有 cluster 也不代表没有硬件异质性。
4. **不要求先完整恢复 SM→GPC 图才开始。** 公开可控的分组加服务能力测量，足以支持底层 A/B 对比。物理归因则要降级表述。
5. **只画热图不算完成。** 映射（map）必须真正被执行。实际分组、计划和任务归属要有针对性的检查。
6. **不用孤立标定代表并发。** isolated 与 concurrent 使用同样的工作量分别测量。部署曲线用代表性并发条件校准。
7. **候选方法必须超过同信息的单速率基线。** 先获得原生、不同任务类型、分组和并发的数据，再确定候选。不能只微调一个已经手工优化过的 kernel。
8. **同一 binary 用于比较运行时策略。** 编译期常量会产生新 binary，需要单独做资格测试。
9. **正确性要求是位级一致加轻量的正式抽检。** CUDA 任务重排保持 kernel 主体不变。位级资格测试加正式输出 screen 足够首轮，不要求形式验证。
10. **计时包含全部真实成本。** 包括表读取、context 切换、launch、join 和计划失效。CPU 框架测试不计作 GPU 研究结果。
11. **连续自主处理。** 缺少特性、慢的策略、有限的负结果都是协议中的正常分支，不是停止理由。只有资源、权限、安全或合同变化才需要询问用户。
12. **已读的公开论文不能当作新贡献复述。** 贡献卡可以写明“只是复现或工程收益”。但也不能把小的正效应写成零。
