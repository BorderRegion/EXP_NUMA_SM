# 本机执行约定 v1

原始协议保留在 GPU_COMPUTE_TOPOLOGY_DUAL_20261014/，以 campaign.json 为准。

- 平台 t10，n_device=1；不推断 GPC 标签、不硬编码 SM 数。
- 本轮用户授权下载、安装和必要清理，覆盖原始 offline 限制；不改变数值合同，不购买/租赁、不自动更改驱动。
- 单 GPU worker；编译最多2并发；每微实验显存 <=512 MiB；应用保留 max(2 GiB, 15%)。
- Green layouts 固定 G0 全量；G1 请求一个 floor(SM/2) 组加全部余数；G2 请求一个 floor(SM/3) 组加全部余数；G3 采用公开 IGNORE_SM_COSCHEDULING 的半分加余数。真实配额以返回值为准；最多4种，不根据性能换分区。
- E2 family×size 条件按 K0-small,nominal,large,K1...,K2...,K3... 固定顺序，轮转 E1 资格通过的 split；三个进程及四种执行模式共享同一 split 选择。
- E2 主矩阵 4家族×3规模×4模式×3独立进程，最多144。32 warmup/128 epochs。先固定时长资格，再冻结规模；所有组隔离和并发使用完全相同的任务和数据。
- E3 最多3混合分布×2负载×7策略×6独立进程。T 若无证据留 NA；N、R为主参考；M唯一类型化并发容量 minimax 方法。
- W1 预定720p，Train/Bonsai 各2开发轨迹、2测试轨迹按相机ID固定划分；Truck留出。不把模型原训练相机称为研究中绝对未见数据。
- 无明显校准增益时 E4 采用 N/R/M 确认分支，每可支持程序2输入×2轨迹×6块×3策略；不能以 synthetic 填补真实程序格子。128帧且>=1s warmup，512测量帧。
- M/N 和 M/R 是预定主比较；块内聚合、条件等权、20000次块 bootstrap；6块探索性，额外比较探索性，不据p值宣称论文成立。
- 精简导出保留所有小型CSV；大输出按每条件最早的成功run，全部关键失败证据保留，绝不按效果挑选。
