# 方案审阅（执行前）

方案有可检验价值，但本轮首先是算子内调度/逻辑复用研究，不再是物理 NUMA 证明。是否优于成熟库、是否优于同融合普通调度、是否包含生产者成本，必须分别回答。

1. **必须先过主体资格。** 本地没有完整 CUTLASS 和 FlashInfer；已安装 Triton 3.4.0 的 SM75 实测 PTX 为 fma.rn.f32，无 mma/wmma，不能当成要求的 Tensor Core 主体。cuBLAS 可用，PyTorch 原生 attention 可用性另做真实 GPU 资格。不能用这个 SIMT 原型制造负结果。
2. **候选会在大部分计划上退化。** 开发集 K 的 75 分位为 2048，因此固定 work_budget 约对应 4096 个 K 元素；K=4096 时 q 上界为 1。所有 32 个最大 K case 的包长都是 1。该规则不保证所有顺序与原生相同，但这部分不可能检验多 tile 包的复用收益。BM=32/64、W=56/112 的有限 CPU 枚举见 design_degeneracy_cpu.json；没有据此改参数。
3. **创新风险。** 同 expert/panel 分组、persistent 调度和负载均衡已有近邻；仅证明固定分组快或 Graph 快都不能成为新方法证据。本包给的论文摘要未离线全文核实，不声称完成查新。
4. **阶段总时限是上限。** 16 worker 小时不是必须消耗完的配额；编译/初始化计入。CPU 开发时间另记。缺可修改后端时做可运行原生成本，不重复百万次无效对照。
5. **统计工具只实现探索性 CI。** 若真正获得 FULL/LIB 和 FULL/S0 两主比较，须补同时区间/Holm；本次原生基线之间的比较不能被标成候选主比较。仍保留 6 独立进程块、主 LIB 和漂移锚。
6. **资产核查要区分完整模型与文本编码器。** 找到本地 Qwen3-0.6B 和 Qwen3.5-4B 命名的权重，不将 diffusion 权重冒称 LLM。完整模型运行须验证 config、权重覆盖、tokenizer 和数值合同；未集成候选不能声称模型调度收益。
7. **资源与范围。** 当前余盘约 8.6 GiB，产物控制在 2 GiB 内、不复制权重；保留旧证据。显存至少保留 max(2 GiB,15%)；大层的全部专家权重必须驻留。当前只执行本机 T10，不预测 5070Ti。

执行决策：先完成两种已安装来源的资格；缺 mutable 高效主体则将 E2 和候选比较列 IMPLEMENTATION_OR_RESOURCE_LIMITED，同时运行可支持的原生算子、完整层及 attention 成本。原计划 216 个 cell 全部保留分母，不用小 case 填补缺项。
