# Resource recovery record

The user explicitly allowed downloads on 2026-10-13. This supersedes the original offline acquisition restriction; benchmarks remain local. No system installer, sudo, driver, kernel, power or clock changes were used.

- Official NVIDIA 13.2.0 redistributable JSON pins nvcc, cudart, crt, CCCL, libnvvm, cuobjdump and nvdisasm. Archive sizes and published SHA256 values were verified. Prefix is workspace-local. A local lib64→lib link resolves nvcc's normal library search layout.
- A 13.4.0 redistributable URL returned HTTP 404; no package was installed from it. CUDA 13.2 supports GCC 15, but its archived OS table omits Ubuntu 26.04. Native sm_120 compilation and execution are the qualification evidence, not a claim of vendor validation for this exact OS.
- Smoke compiled with native sm_120 only, and all 32768 uint outputs matched the independent CPU expression. cuobjdump confirms native cubin. Driver/runtime query: 13020/13020.
- Initial smoke macro variable shadowing was corrected; no GPU launched from failed compile. Supplied inventory referenced cudaDeviceProp.kernelExecTimeoutEnabled, absent in CUDA 13.2: only a new src/device_inventory.cu copy was corrected to emit null; immutable proposal source preserved.
- Upstream rasterizer commit 59f5f77e3ddbac3ed9db93ec2cfe99ed6c5d121d; GLM submodule 5c46b9c07008ae65cb81ab79cd677ecc1934b903. CMake forces native 120-real and pre-includes cstdint because the upstream header relied on a transitive include; no rendering arithmetic changed.
- Python/PyTorch bindings were absent. The C++ API permits a thin headless adapter. It loads official binary Gaussian PLY fields, activates scale/opacity and normalizes quaternions, converts the camera JSON and calls unmodified preprocess/binning/sort/render. It is explicitly 'fixed upstream core + headless adapter', not the full official Python application or a SOTA claim.
- Official model ZIP metadata was read by HTTP Range. Selected before policy measurements: train (small outdoor), bonsai (small indoor), truck (independent heldout). Iteration 30000, SH3, black background. Range bodies and ZIP CRCs verify extracted identity; SHA256 locks are recorded. Never unpickle cfg_args/model objects; cfg_args is plain-text source metadata.
- First large model range requests timed out after partial transfers; completed files were retained. Resume downloader uses 8 MiB ranges with at most three attempts and stores compressed progress. An accidental eager import of the earlier downloader was immediately stopped (only our own CPU download process) and removed before resume.
- Camera replay matrices follow the published camera_to_JSON/graphics_utils conventions, using full 3x3 inversion and float32 matrices, near/far 0.01/100. Host arithmetic can differ from PyTorch activation/matrix arithmetic: no external bitwise equivalence claim. Schedule comparisons will share these exact inputs.
- Direct CUDA headers have no LOCALITY_DOMAIN declarations; this alone is not hardware evidence. No SM binding or physical NUMA domain is inferred from IDs.

- First joint planner qualification failed its CPU coverage check before candidate render: greedy first selection could consume a later neighbor and skip the anchor on the next outer iteration. Fixed by always seeding each bundle with the first remaining anchor. Original failed output is preserved in executor_checks; retry uses executor_checks_r2. No correctness tolerance changed.
