# 来源、署名与保存范围

## 这些文件从哪里来

- 所有实验文件来自本机项目 `numa_gpu`，以及任务相关的下载压缩包、回执和桌面交付目录。
- 本仓库里的 `docs/` 和本页 `README.md` 是整理层，是 2026 年 10 月这次文档重写的产物。
- `experiments/` 下的文件是原始记录，**字节不改**。

## 没有保存的内容

- `.git` 数据库、Python 字节码、可以重新生成的解释器缓存，不计入实验记录。
- 主项目的 Git 历史另外以 bundle 形式保存。
- 第三方仓库的 `.git` 数据库不包含。它们的源码、版本号和来源锁都保留。
- 没有扫描或打包其他个人目录、浏览器登录信息或认证凭据。

## 署名

- 仓库 `BorderRegion/EXP_NUMA_SM` 的所有者是 BorderRegion。
- 本次整理的提交使用 `BorderRegion <145738446+BorderRegion@users.noreply.github.com>`。
- 既有的 Git 历史保留当时的作者信息（其中包括 Codex 生成的提交）。我们不改写它们，也不声称它们是用户原创。

## 第三方内容

下列第三方内容保留其原始来源和许可证，本仓库**不**把它们重新授权为原创：

- Graphdeco 3D Gaussian Splatting 及其 rasterizer；
- 原作者的模型和相机数据；
- SNAP 图数据；
- NVIDIA CUTLASS；
- 同版本的 open-gpu-kernel-modules 源码；
- 工具链和运行库的记录。

仓库没有加一份统一的开源许可证来覆盖全部第三方内容。复制归档**不改变**它们的版权或许可条件。

## 归档和校验

- `archive/manifests/` 记录每个文件的 SHA256、大小、修改时间、权限和归档路径。
- 同一个文件可能在多个交付包或冻结源码副本中重复出现。这是原始记录的一部分，**不能**因此把重复计作独立的实验量。
- 归档包本身也逐一计算了 SHA256，见 `archive/SHA256SUMS`。

## 不做的事

- 不改写冻结的协议或历史数据。
- 不覆盖旧的 ZIP 或原始文件。
- 不因为整理文档而增加 GPU 实验。
- 历史报告中的机器路径、GPU UUID 和功耗监测信息，是实验的来源信息，保留原样。
- 历史报告中的“未来工作”或“不要追加实验”等文字，只是当时的记录，**不是**发布后要执行的指令。
- 恢复工具不执行报告里的任何命令。
